## Failures and repairs retained

1. The relay was not running at the start.
2. EGO's first restart lost session-only variables and selected port 3000 plus
   Gemini. It was stopped before any task and restarted as the deterministic
   baseline.
3. The first relay child inherited Windows `RELAY_HOST=127.0.0.1`; it was
   stopped and rebound to `0.0.0.0`. Its diagnostic also incorrectly treated a
   short-but-valid runtime token as absent; presence replaced length.
4. Windows could not reach WSL EGO through localhost forwarding. The relay used
   the current WSL IP after a direct health check.
5. Dynamic `Start-Process` variables did not survive in the hidden relay child,
   producing event `502` despite both upstreams returning 200. Persisting the
   ignored private configuration repaired the feed to HTTP 200.
6. The old EGO process had held Nigma URL/key and human-decision token only in
   memory. A local atomic configurator copied the active Nigma key without
   output, generated a new independent 64-hex human token and changed `.env`
   from `0644` to `0600`.
7. The preparation summary initially looked for obsolete nested field names;
   the valid preparation was retained and the current `plan`, `runtime` and
   `approval_target` fields were used.
8. Direct PowerShell invocation of Hermes' packaged Node returned neither
   stdout nor `LASTEXITCODE`; `Start-Process -Wait` plus unique temporary output
   files restored sanitized doctor/bind/watch output.
9. The first watcher failed closed before scanning because WSL-IP HTTP is not a
   permitted EGO URL. The already-sent human turn stayed after the sealed
   baseline. A temporary raw TCP bridge bound only to Windows
   `127.0.0.1:3001` and forwarded to EGO; the same binding then recorded the
   approval on its first scan.
10. The first bridge runner requested both `node.exe` and absent `node` with
    terminating error behavior. Selecting Hermes' explicit Node path repaired
    startup. An earlier inline PowerShell launch also failed argument parsing;
    reviewed temporary scripts replaced nested escaping.
