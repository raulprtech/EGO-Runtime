# G1.9 — trusted conversation human decision

Date: 2026-08-15.

## Outcome

EGO now exposes `POST /v1/runtime/nigma/conversation-decisions`, a neutral host
port that converts exactly one externally authenticated human `user` turn into
the G1.8 approval request. It does not implement Hermes chat endpoints and does
not change ARIA.

The strict request requires the sealed preparation/projection, `role=user`,
`origin=externally_authenticated_human`, opaque conversation/message
references, an observation timestamp, exact message content, approver and
absolute expiry. It is protected by both the runtime bearer token and the
separate human-decision credential. An assistant/tool role cannot parse; any
prefix, suffix or altered byte fails the challenge hash; a turn outside the
sealed presentation window fails before Nigma.

EGO domain-separates and hashes the opaque conversation and message references.
Only those hashes, the observation time and existing sealed target evidence
reach Nigma. The raw phrase and raw references are absent. The returned
`nigma.trusted-conversation-decision-record/v1` nests the independently sealed
G1.8 approval and remains `execution_performed=false`. G1.9 also strengthens
G1.8 by requiring Nigma to return the exact canonical evidence object rather
than merely matching a subset.

## Retained failures and repairs

1. Architecture discovery confirmed ARIA currently targets Hermes' session
   stream. EGO therefore gained a neutral decision port instead of copying that
   proprietary conversation API or changing the mobile application.
2. The first isolated-start command referenced the already cleaned G1.8
   temporary database and failed before starting a process. G1.9 generated a
   fresh database through Nigma's versioned fixture builder.
3. Positive automated tests use a strict mock, but the real checkpoint did not
   synthesize a human role. Work paused at the exact phrase until the owner
   supplied it verbatim; execution remained a separate untouched operation.

## Remaining integration boundary

This proves the neutral trusted-host port and a real owner decision from Codex.
A production Hermes/EGO/Olimpo conversation adapter must possess the separate
human credential, derive trustworthy actor/message metadata from its own
authenticated session and call this port. That adapter must never expose the
credential to the model or ARIA client.
