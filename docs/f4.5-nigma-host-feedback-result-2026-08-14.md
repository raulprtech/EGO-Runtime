# F4.5 — Nigma host feedback loop

Date: 2026-08-14

## Outcome

EGO 0.8 implements the first reference host coordinator for Nigma. Given only a plan ID, learner routing context and an idempotency key, it requests the already-approved invocation from Nigma, chooses an operator-owned exact runtime route, transports the sealed envelope, observes terminal execution, retrieves a strict receipt and returns it to Nigma.

The live local gate started real Nigma and EGO processes on separate loopback ports. A Markdown source completed through the deterministic provider; Nigma accepted the receipt, closed its ExecutionRun as `succeeded`, created exactly one ExperienceRecord and returned the same receipt after replay. HermesMobile/ARIA and Olimpo were not modified.

## Safety and ownership

- The host cannot approve a plan or accept a caller-provided invocation.
- Nigma selects runtime identity/version but never sees runtime URLs or credentials.
- The host owns exact routes and resolves credentials only from bounded environment-variable names.
- Non-loopback plaintext HTTP, embedded URL credentials, duplicate routes and unknown runtime versions fail closed.
- Upstream schema violations return a transport-contract error instead of being misclassified as caller validation.
- EGO still revalidates the route, provider bindings, permissions, input scheme and local-file confinement before execution.
- The complete mapped learner context participates in EGO idempotency.
- Nigma receipt acceptance atomically precedes the successful host response and idempotently records experience.

## Attempts, failures, errors and repairs

- The first mechanical endpoint import edit used an incorrectly escaped Perl pattern. The import did not apply; inspection showed the route had applied, and only the missing import was repaired.
- The first focused EGO run failed 1/8 because a manifest expectation did not include the new host-orchestration fields. The exact expectation was updated; behavior was already correct.
- A follow-up expectation edit also had a malformed Perl expression and was rejected before writing. A smaller exact substitution succeeded.
- Updating Nigma's seeded EGO version exposed one stale Experience Store assertion. The first replacement missed the literal `@`; the corrected exact replacement passed 43/43.
- The persistent-fixture test could not import `scripts` because pytest intentionally exposes only `src`. Adding `__init__.py` did not change that boundary. The temporary file was removed and the test now invokes the real generator CLI, passing 44/44.
- Review separated upstream schema failures (`502`) from invalid caller bodies (`400`) so a compromised or drifting service cannot blame the user request.

## Deferred

The host endpoint is synchronous and bounded to 120 seconds. Durable asynchronous host-run state, production service identity, signed envelopes, runtime health scoring and the interface-facing session/event adapter remain future gates. The deterministic provider proves system flow, not pedagogical equivalence to Gemini.
