## Product repairs after the rehearsal

1. Configured handoff preparation now validates runtime identity, required
   capabilities, local route and route credential before creating a human
   challenge. Missing `assessment` returns 422 and creates no challenge; the
   repaired policy succeeds.
2. The sidecar parses structured errors before classifying 401. Only explicit
   authentication errors become `UPSTREAM_AUTH_FAILED`; host/runtime policy
   errors remain `UPSTREAM_REJECTED` with a sanitized reason.
3. Learner-facing messages no longer mention Nigma, internal UUIDs, full
   digests or runtime-selection scores. They use a deterministic short plan
   code and neutral `learning.plan` label. Sealed evidence is unchanged, and
   legacy events are neutralized only when projected.

## Retained operational failures and decisions

1. Direct Windows Node doctor output was empty; `Start-Process -Wait` with
   explicit capture repaired observation.
2. An initial PowerShell port query was altered by Bash `$` expansion; literal
   quoting repaired it.
3. A watcher reader used invalid PowerShell inline `if` syntax; corrected
   assignment syntax and durable binding/database evidence confirmed state.
4. An attempted `0.0.0.0` EGO listener was rejected during approval review.
   Exact-interface EGO plus loopback-only bridges replaced it.
5. Windows could not reach WSL loopback directly; scoped bridges solved host
   traversal and were deleted after testing.
6. The patch sandbox lacked `bubblewrap`; interactive `apply_patch` preserved
   the required editing path.
7. The first audit expected a historical `agent_route` root field. Inspection
   used the current sealed topology instead.
8. Attempt one exposed the missing `assessment` policy and remained failed;
   attempt two used a new plan after deterministic repair.
9. The sidecar misclassified a structured host 401 as authentication failure;
   parsing and regression tests now distinguish both cases.
10. Vite reported its already-used development WebSocket port 24678; HTTP
    execution was unaffected and no active development service was replaced.

No model, VPS, GPU, APK, clinical data or personal file was used. The input was
a synthetic educational note. Login and mobile changes remain outside G1.17.
