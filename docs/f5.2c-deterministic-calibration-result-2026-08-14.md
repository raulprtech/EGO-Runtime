# F5.2c deterministic bilingual calibration

The real learner run showed that exact English-token overlap was reproducible but educationally misleading. The replacement baseline is identified as `deterministic-bilingual-v1` and returns matched/missing elements plus `mastered`, `partial_match`, `uncertain` or `insufficient_evidence`. External providers remain compatible through the `provider_scored` default and may omit a calibration identity.

Seven frozen synthetic cases cover the current Nigma lesson in Spanish and English, including functional equivalence, partial retrieval, explicit uncertainty and confident irrelevant content. The vocabulary is deliberately limited and reviewed; no generic semantic capability is claimed.

Retained failures:

- generic tokenization initially removed the short negation in Spanish uncertainty; intention normalization is now separate;
- TypeScript found two manually constructed result fixtures missing new fields; both now state their evidence/reason explicitly;
- the cross-runtime Nigma golden depended on an obsolete Spanish summary prefix and now validates the versioned semantic contract instead.

Final evidence is 35 passing EGO tests with one cloud skip, clean TypeScript, 494 passing Nigma tests and a cross-runtime 3/3 golden with stable replay, one ExperienceRecord and no raw-answer retention. The historical real 0/3 result remains immutable.

Implementation commits `a12dde3` (EGO) and `6fce5d7` (Nigma) were verified from no-hardlink clones using only local dependency caches. The clones repeated all 35/494 tests, TypeScript and the complete versioned cross-runtime golden without network or retained raw answers.
