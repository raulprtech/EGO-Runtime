# G1.5 — verified runtime-decision explanation

Date: 2026-08-14.

## Outcome

EGO now accepts Nigma's optional
`nigma.runtime-decision-explanation/v1`, validates its strict bounded schema,
recalculates its canonical SHA-256 and checks its exact selection/runtime/
version/snapshot binding. It also recalculates factor sums, deltas and score
margin. Only then does it expose a compact
`runtime_decision` in `nigma.host-preparation/v1`.

The projection includes selected score/evidence basis, runner-up, score margin,
factor deltas, reason codes and the immutable authority state
`human_approval_required`. It contains no endpoint, credential, learning
material or model reasoning. EGO still cannot approve or execute during
preparation.

Preparations created before G1.5 remain accepted without the optional field.
If an explanation is present with a changed digest or selection link, EGO
returns 502 before presenting it.

## Cross-process evidence

An isolated EGO process on loopback port 3001 consumed the real Nigma/Python
object and reproduced digest
`789bf623687468814645d7d17f19d7cb2cdeb60bd9591c08e6890f0398ce387b`.
It projected EGO 912897 ppm, Hermes 686190 ppm, margin 226707 ppm and all six
factor deltas. Approval and execution remained false. Repeating the same key
after a Nigma restart returned the identical plan and explanation. The isolated
process was then stopped; the normal local EGO service was not replaced.

## Retained failures and repairs

- `npm` resolved to the Windows Hermes shim and could not find Node in WSL. The
  existing Linux VS Code Server Node ran Vitest, TypeScript and builds without
  installing anything.
- The first real request was rejected by Nigma because a newly absent optional
  field changed historical fallback digests. Nigma preserved the old absent
  representation while sealing explanations in new fallbacks; the unchanged
  retry then passed.
- Nigma's first unit expectation attributed runner-up Hermes evidence to
  selected EGO. The test now requires per-runtime evidence attribution.
- The new arithmetic verifier rejected the focused fixture because it declared
  750000 ppm while representing only one 200000-ppm factor. The synthetic
  selected/runner-up totals were aligned with that factor; production checks
  were not weakened.

This layer explains the deterministic decision; it does not endorse the scoring
policy and does not turn EGO into the authority that made it.
